## [0.3.0-beta] - unreleased (branch `beta-0.3.0`)

(0.2.6) preserved — changes here are additive or with a deliberate bump.

### In development

  - **KofScript became a direct execution target with an IR interpreter
    (06/09)** — `KofInterpreter` executes the SAME optimized IR that the JVM
    backend consumes (same frontend: parse → merge → imports → desugar → analysis
    → lowering → optimization), without emitting bytecode and without a JVM fork.
    Parity by construction, proven in a test (byte-identical output to the compiled
    JVM: functions, strings, records with content `==` + toString,
    collections with higher-order, mutable classes, while/for-in,
    try/catch/finally with throw-as-String, spawn/await). `CompilerDriver`
    gained `interpret(...)` (public facade) and the extracted steps
    `parseAndMerge`/`analyzeAndLower` (pure refactor, zero-regression).
    JS/Native remain on the compiled path; `runFileCompiled` kept as
    fallback and parity proof. Docs corrected: KofScript is NOT a separate
    language nor JavaScript — it is pure Kof on the same frontend.
  - **`fn`/`fun`/`func` became reserved words in Kof (06/09, SG-001)** —
    the documentation always said that "there is no `fun` or `func`" (AGENTS.md,
    fake-idioms.md), but the compiler accepted `fn` as a prefix and `fun`/`func`
    as an implicit return type. Now all three are **reserved words in the
    lexer** (tokens `FUN`/`FN`/`FUNC`, same mechanism as `sealed`/`permits`):
    they **do not exist** in Kof in any position — neither as a declaration
    keyword, nor as a function/variable/parameter/field name. In declaration
    position it gives **`PARSE085`** (clear diagnostic: "declare as
    `Tipo nome(...) { }` or `nome(...): Tipo { }`"); in another position each
    parser's `expectId` already fails (`PARSE037` variable, `PARSE023` parameter).
    Code↔corpus alignment (rule 4). **KofScript (`.ks`) is no exception** — it is
    pure Kof (see the KofScript entry below); `fn`/`fun`/`func` there also give
    `PARSE085`. Deliberate, documented breaking change: `.kf` code that used
    `fun`/`fn`/`func` (even as an identifier) now needs to be renamed.
    Proof: `FunctionSyntaxTest` (12 cases) + KofScriptTest 8/8 + full suite 957/0.

  - **KofScript is pure Kof — JavaScript sugar removed (06/09, maintainer's
    design fix)** — the pipeline carried sugar from another language:
    `let`→`var`, `const`→`val`, `async fn`→`fn`, and an "own" `fn` translated
    at the `.ks`→`.kf` boundary. **KofScript is not JavaScript**: it is the target
    where Kof code runs directly, without separate compilation. Removed `preprocess`,
    `normalizeVoidFns`, `toKofSyntax` and the 3 copies of the wrap logic
    (KofScript/CmdScript/LspServer) — replaced by a single `wrapPureKof`
    that only does the **script execution model**: top-level statements become
    `main()`, top-level `var`/`val` become `KofScriptGlobals`. `let`/`const`/
    `async`/`fn` now give the normal Kof parser diagnostic in `.ks` too
    (R6: never silent). Deliberate breaking change: `.ks` that used sugar
    needs the Kof form. Proof: `KofScriptTest` 9/9 (includes `jsSugarIsRejected`
    — `fn`/`let` in `.ks` → `PARSE085`) + full suite.

  - **NATIVE002-stdlib residual (05/09)** — R6 audit + cross parity:
    **fcvt riscv64** (the 10 numeric conversion mnemonics came out with
    rd/rs swapped — `as Int`/`as Double` broke on `as`),
    **ToolchainMissing** (`as`/`ld` failure on the cross now propagates as a
    compilation error — before it was a silent "success=true without binary"),
    **FLT001** (`println(double)`/`valueOf(double)` on the cross becomes a
    compile-time diagnostic: pure asm runtime without libc has no `%g` —
    before it was a silent segfault; FP arithmetic/conversion works),
    **real time.now()** (`clock_gettime` 113 — it was a `li a0,0` stub that
    broke the cache TTL), **riscv64/aarch64 cache** (scan loops used
    t2/t3 clobbered by `kof_string_equals` → segfault; + `sle/sge`
    nonexistent in the riscv ISA → `<=`/`>=` broke; + `println(null)`→"null"),
    **mq riscv64/aarch64** (full port: queue by handle, pop via
    `kof_list_remove`, queue_size, unsubscribe by identity, invoke of the
    handlers via vtable — before it was nonfunctional: MQ001 gate). Proof:
    `KofMqE2ETest` 5/5 (incl. cross qemu with output parity),
    `riscv64/aarch64Cache`, `riscv64/aarch64TimeNow`.
    **tail-call in 8 riscv functions** (`call`+`ret` without saving `ra` = infinite
    loop — `observability.health`/ids/`time_interval` hung),
    **SCHED001/TIME001/SECN000 gates** (scheduler/time.interval/kof_sec_*
    missing in the cross runtime → clean diagnostic instead of undefined-reference
    at link or silent no-op), **`"42".toInt()`** (deref of the char VALUE
    as an address → SIGSEGV), **Map/Set + higher-order** on the cross
    (`RISCV_MAPSET_ASM` linear-scan; closure ABI of mq), **`kof_panic`**
    prints C-string (bounds-check message), **scalar json decoders**
    (int/long/bool/string), **bug 30** (`decode<Bool>("false")`→true on
    x86_64: length in the wrong register + offset ignored), **metrics()
    `# TYPE`** on the cross + **quote-aware translator** (`.asciz "# TYPE "` was
    stripped as a comment → unterminated string on aarch64). Parity sweeps
    (KSw/KSw2/KJ/KU/KMR3/KCFG/KVAL): **0 divergences** in the 3
    targets. Bugs registered outside the lane: #29 (`spawn { lambda }` with
    handle), #31 (`process.<nonexistent>` compiles as a field access),
    #28 (ws flake). Full suite 962/0/3-skip.

  - NATIVE002 advanced parity riscv64/aarch64: real stdlib in the asm runtime —
    **JSON** (`kof_json_quote`/builder, encode/decode record+lists), **HTTP**
    (`get/post/put/patch/delete/options/status` + headers, pure asm: socket+
    connect+write/read/close, asm-generic syscalls) and **spawn/await** (`clone`
    + `futex` — qemu-riscv64 8.2.2 does not implement clone3; heap shared
    between main and workers → `kof_alloc` became an atomic bump `amoadd.d`) closed
    (19/19 qemu each target); aarch64 inherits via `translateRiscvToAarch64`.
    Codegen fix: `--no-relax` in the riscv64 as/ld (gp-relaxation faulted with
    gp=0 in the static binary). aarch64 translator fixes: `movz` (not `mov`)
    for immediates with `lsl #16`; hex immediates in `li`/`addi`/`andi`;
    `amoadd.d`→`ldadd` + `.arch armv8.1-a`; `fence`→`dmb ish`. **db**: the dynamic
    link of libsqlite3 requires libc — unfeasible in the pure static asm; the cross
    now report **DB001 at compile-time** (R6: never undefined-reference at
    ld), locked by `crossNativeReportsDb001`. **String methods riscv64/aarch64**
    (`trim`/`toUpperCase`/`toLowerCase`/`replace` char+String/`lastIndexOf`/
    `equalsIgnoreCase`/`split`) implemented in pure asm — before they broke at
    link with silent undefined reference (R6); `RISCV_RUNTIME_ASM` split
    into 3 constants (javac's 64KB limit). Proof: `riscv64/aarch64StringTrimCaseReplaceSplit`
    + suite 913+8+5+8.
  - GC auto-collect (safe-points + per-frame root map).
  - Package manager MVP (`kof init`/`kofdeps`/registry).

## [0.2.6-beta] - 2026-09-02

### Feature — switch as an expression (SYN001)

- **`case ... ->` producing a value** (`feat`): `var r = switch (x) { case 1 ->
  "um"; default -> "outro" }` — pattern matching via expression, in the spirit of
  the Java 14 switch expression. Each case is a single expression (no `break`,
  no block scope, no fallthrough); `default` required or
  enum exhaustiveness (otherwise `SEM032`). Works in the 3 targets + riscv64/aarch64 (JS
  renders as nested ternaries). **Additive**: the statement form
  (`case X:`) is untouched. Proof: `KofSwitchExprE2ETest` 19/19 +
  `NativeRiscv64E2ETest`/`NativeAarch64E2ETest` 14/14. Plan in
  `docs/planning-switch-expr.md`.
- **PKG005: transitive re-import is not a collision** (`fix`): `compileSources` with
  explicit source + `import` of the same declaration triggered a false positive for
  "duplicate type name"; now it only collides when the **files** differ
  (`PackagesE2ETest` 7/7).

### Fix — idiomatic philosophy (corpus review)

- **`Set<T>` as a declared type on the JVM** (`feat`): descriptor `kof.Set`

  return and parameter now works in the 3 targets — previously `NoClassDefFoundError:
  kof/Set` on the JVM (`KofMapSetTest`).
- **Parser: class members with generic return** (`fix`): `Set<Int> foo()`,
  `List<String> bar()` in class did not parse (1-token lookahead).
  Refactored to parse-then-decide (`Parser.parseClassMember`).

  s.length }` emitted `getfield "?".length` and `s.substring(...)` emitted

## Versioning

Kof uses `MAJOR.MINOR.PATCH` (see [docs/distribution/VERSIONING.md](docs/distribution/VERSIONING.md)).

- `0.0.x-alpha` — initial stage (Alpha), each commit on `main` generates the next version.
- `PATCH` is the *little dot of shame*: bugfixes, corrections, regressions and small adjustments.
- Nothing is called stable while it is in Alpha.

## [0.0.4-alpha] - 2026-08-22

### Distribution infrastructure

- Centralized versioning: `VERSION` as the single source, `<revision>` in Maven,
